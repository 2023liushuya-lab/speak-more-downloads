# Speak More 下载

Speak More 是一款 macOS 语音输入工具，支持本机识别或使用自己的云服务。当前 Beta 面向 macOS 14 或以上版本的 Apple Silicon Mac。

[查看发布版本和下载附件](https://github.com/2023liushuya-lab/speak-more-downloads/releases)

下载带有 `macOS-arm64.dmg` 后缀的文件，将 Speak More 拖入“应用程序”。beta.3 及更早版本需要手动安装首个支持自动更新的版本。自 beta.4 起，发现新版时可以在客户端点击「更新并重启」，也可以到「设置 → 软件更新」手动检查。

每个版本的附件包含安装包、签名更新包、校验和，以及 AGPLv3 对应源码快照。测试版采用开发签名，尚未经过 Apple 公证，更新后 macOS 可能要求重新确认权限。

Speak More 基于 [OpenLess](https://github.com/Open-Less/openless)。许可见 [LICENSE](LICENSE)；详细来源与第三方声明随对应源码提供。
